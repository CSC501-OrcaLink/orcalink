# OrcaLink
Modeling potential social ties in Southern Resident killer whales

# Overview
OrcaLink is a CSC 501 project at the University of Victoria. The project aims to combine whale identity, family relationships, and sighting records in a data model that supports queries about diirect and inidirect connections among Southern Resident killer whales.
The model will distinguish family relationships from recorded co-sightings. Whales recorded together in an encounter are not necessarily closely socially connected.
